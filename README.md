# NetIntellect

NetIntellect is a high-performance, client-side intelligence dashboard built to instantly ingest, merge, and map relationships from multi-source logs into a unified, interactive relationship graph[cite: 1]. Designed for investigative agencies, cyber cells, and financial crime units, it helps users quickly uncover connections across unstructured data silos[cite: 1].

## Features

- **Multi-Source Ingestion:** Simultaneously upload and parse multiple CSV or text log files[cite: 1].
- **Dynamic Relationship Mapping:** Automatically unifies nodes and edges to create an interactive network graph visualization[cite: 1].
- **Entity Inspector:** Click on any node to inspect details, trace connection paths, and view relevant metadata.
- **Advanced Intelligence Metrics:** Highlights critical bridge nodes and structural data points within complex networks[cite: 1].
- **Zero-Latency Client-Side Engine:** Runs entirely in the browser for fast, responsive interaction[cite: 1].

## Tech Stack

- **Frontend:** React, Vite, TypeScript, Tailwind CSS
- **Icons:** Lucide React[cite: 1]
- **Visualization:** Custom SVG-based Network Graph Renderer[cite: 1]
